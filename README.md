# Notable Projects

[ **<span class="sans-serif">tagger</span>** ](
    https://github.com/\github/tagger
) Python ⋅ Keras ⋅ TensorFlow ⋅ Weights & Biases

Trains a bigram-convolutional neural network over SpaCy embeddings to
predict emotion labels on Reddit comments.

The network design was motivated through evaluation of various models
and systematic hyperparameter optimization.

[ **<span class="sans-serif">convector</span>** ](
    https://github.com/\github/convector
) Python ⋅ Gensim

Applies distributional semantics and semantic matching toward an
automated solver for the New York Times Games Connections puzzle.

Trains CBOW embeddings on Wikipedia and clusters the context vectors via
DBSCAN to identify distinct meanings before grouping different words’
senses by cosine similarity.

[ **<span class="sans-serif">asofterworld</span>** ](
    https://github.com/\github/asofterworld
) Python ⋅ OpenCV ⋅ BeautifulSoup

Bridges syntactic theory and NLP to explore whether panel divisions in
the webcomic *A Softer World* separate syntactic consituents.

It scrapes the webcomic’s images then detects and partitions panels,
assigning OCR-extracted text according to panel boundaries, and passes
that text to an NLP pipeline.
