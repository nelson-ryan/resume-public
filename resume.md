# Notable Projects

[ **<span class="sans-serif">tagger</span>** ](
    https://github.com/\github/tagger
) Python ⋅ Keras ⋅ TensorFlow ⋅ Weights & Biases

A course project and CodaBench competition, this builds and trains a
convolutional neural network to tag social media comments.

[ **<span class="sans-serif">convector</span>** ](
    https://github.com/\github/convector
) Python ⋅ Gensim

An exploration into semantic matching and word-sense disambiguation to
create an automated solver for the New York Times Games Connections
puzzle.

It trains CBOW embeddings on Wikipedia and clusters the context vectors
via DBSCAN to identify distinct word senses.

[ **<span class="sans-serif">asofterworld</span>** ](
    https://github.com/\github/asofterworld
) Python ⋅ OpenCV ⋅ BeautifulSoup

An early vision in language processing, this project aims to generalize
syntactic patterns from an existing webcomic.

It performs webscraping to retrieve images and uses third-party OCR to
extract text and pass to a SpaCy or Stanza pipeline.
